43Main dalam office

Interaksi seronok dalam pejabat pixel: usik agent, buka menu pantas, heret watak ke zon aktiviti berbeza, dan kawal watak bos awak sendiri.

👉 Poke (Usik)
Tap mana-mana agent untuk usik. Dia akan melompat gembira. Tap 4 kali laju-laju = dia marah 💢!
⭕ Radial Ring Menu
Tekan lama (500ms) atau klik kanan tetikus pada agent untuk buka menu bulatan pantas.
🚶 Watak Bos Sendiri
Watak pixel awak (baju bos) berjalan ikut tap lantai atau kekunci arrow / WASD.

Interaksi Tetikus & Sentuhan

  • Cucuk (Poke): Klik atau tap pada agent. Jika dicucuk 4 kali berturut-turut dalam masa 6 saat, agent akan hilang sabar dan keluar emoji marah 💢.
  • Menu Bulatan (Radial Menu): Buka dengan klik kanan atau tekan lama. Mengandungi 5 butang pilihan:
    • Chat: Buka perbualan langsung dengan agent tersebut.
    • New job: Cipta tugasan pantas untuknya.
    • Pause / Resume: Rehatkan atau aktifkan semula agent.
    • Memory: Intip nota memori yang disimpan oleh agent.
    • Poke: Usik agent.
  • Heret & Lepas (Drag & Drop): Angkat mana-mana watak agent dan lepaskan ke zon pejabat:
    • Lepas di pantry: Agent pergi bancuh dan nikmati kopi ☕.
    • Lepas di meeting room: Masuk ke meja bilik mesyuarat.
    • Lepas di library: Duduk membaca buku di rak perpustakaan.
    • Lepas di whiteboard: Membuka skrin Drafts terus.
    • Lepas di meja bos (your desk): Membuka tetingkap Chat dengan agent tersebut.
    • Lepas atas agent lain: Kedua-dua agent akan berdiri bersembang bersama.
  • Berjalan Bersama: Bila watak bos awak berjalan menghampiri mana-mana agent (dalam jarak 40 px), agent akan berpaling memandang awak dan butang "Chat with [Nama]" akan muncul di bawah skrin.
  • Lompatan Hati (Heart Hop): Bila awak meluluskan draf mereka di Drafts atau Telegram, agent tersebut akan melompat gembira dengan emoji hati (heart ❤️)!

41Rooms (bilik)

Pengasingan ruang kerja (workspace) mengikut projek, cawangan perniagaan atau ahli pasukan, dengan kawalan bajet AI dan alatan yang selamat.

🏛️ HQ Utama (owner)
Ruang induk pemilik MyOfis. Kawalan pentadbir penuh, sambungan runners, AI providers dan semua fail sistem.
🚪 Room (Bilik Pasukan)
Dicipta oleh pemilik untuk sub-bisnes atau projek khas. Boleh dikongsi bersama ahli pasukan (members).
👤 Personal Room
Bilik peribadi untuk setiap ahli jemputan menjalankan kerja sendiri menggunakan kuota atau API key mereka.

Pengurusan Bilik

  • Cipta Bilik: Buka menu Rooms (/rooms) untuk tambah bilik baharu, tentukan nama, dan tetapkan had bajet harian AI (Daily token budget).
  • Pemilik Masuk Mana-Mana Bilik: Pemilik (owner) bebas bertukar ke mana-mana bilik pada bila-bila masa. Ahli biasa hanya boleh melihat bilik yang mereka dibenarkan masuk.
  • Pindahkan Agent & Projek: Gunakan butang Move to room pada kad agent (jadual cron miliknya akan dipindahkan sekali) atau pada kad projek (folder brief dan draf turut berpindah).
  • Peralatan Selamat (MEMBER_TOOLS): Di dalam bilik yang dikongsi bersama members atau bilik peribadi ahli, agent hanya dibekalkan alatan selamat—tiada akses terminal shell luar, tiada manipulasi fail OS di PC runner pemilik, dan tiada OpenCode.
  • Penukar Bilik (Room Switcher): Terletak di bahagian atas sidebar dan bar telefon untuk beralih konteks bilik secara serta-merta (menggunakan kuki ao_room).

Format Jawapan Bersepadu Ketua

Daripada jawapan berasingan yang berselerak, Ketua menyatukan semua pandangan dalam satu format kemas:

  • Ringkasan (Verdict): Keputusan ringkas sama ada idea awak praktikal dan disyorkan atau tidak.
  • Pandangan Pasukan: Analisis khusus mengikut peranan (contohnya pandangan pasaran dari Marketing, isu kapasiti dari Kerani, aspek teknikal dari Coder).
  • Risiko: Potensi masalah, kos tersembunyi atau risiko operasi.
  • Langkah Seterusnya: Pelan tindakan bernombor (1, 2, 3) yang siap untuk dilaksanakan.

Bila awak berpuas hati, cuma balas "ok proceed" atau "proceed" dalam chat, dan Ketua akan menyerahkan tugasan kepada agent berkenaan.

Taklimat Pagi (Morning Briefing) Jam 07:30

09Publisher: post terus ke website

📷 Gambar + point→Publisher tulis→Drafts / kad Telegram→✅ Approve→Website SmashPoint+Media sosial
Aliran Kerja PublisherPipeline
  1. Chat (atau Telegram) → Publisher → projek SmashPoint → 📷 gambar → point. Contoh: "Tournament doubles Sabtu 24 Okt 9 pagi, hadiah RM500, yuran RM20 seorang, daftar kat kaunter".
  2. Publisher sebut apa dalam gambar; kalau maklumat kurang dia tanya satu soalan.
  3. Dia buat post website (tajuk, ringkasan, isi, jenis, tags, tarikh/masa/tempat, cover) + caption dengan gambar sama.
  4. Drafts / kad Telegram → semak. Sebelum approve, semua medan boleh diubah: tajuk, ringkasan, jenis, tags, tarikh, masa, tempat, Change cover / Remove cover, isi.
  5. Approve → terus publish → View it on the website →.

50Status kerja, had & Stop

Kawal selia kerja ejen dengan jelas: fasa status secara langsung (kad status), pantau barisan kerja melalui Work queue, butang Stop pantas bila tersangkut, dan 5 benteng keselamatan had pelaksanaan.

📊 Fasa Status Jelas
Kad status menunjukkan fasa: queued (tempat & sebab), running (langkah & timer live), quiet, failed, dan cancelled.
🛑 Kawalan Stop & Try Again
Butang Stop membatalkan kerja serta-merta di hub. Butang Try again menghantar semula arahan tanpa perlu taip balik.
📑 Work Queue (Giliran)
Tile di bawah sidebar: "N running · M waiting". Buka popover di desktop atau bottom sheet di telefon untuk pantau giliran.

5 Benteng Had Pelaksanaan (Run Limits)

BentengHad LalaiTindakan Sistem
1. Had Langkah (Steps)Mengikut max_steps ejenBerhenti bila mencecah had langkah alatan.
2. Had Masa (Time)max_run_minutes (lalai 20m)Hub membatalkan kerja automatik bila terlebih masa. Masa tunggu approval atau consult tidak dikira. Video/OpenChatCut dapat minimum 60m; direct render 120m.

Fasa Kad Status (RunStatusCard)

  • queued: Paparan cip barisan (cth #2 in line), tempoh menunggu, dan butiran sebab (runner sibuk, sistem paused, atau tunggu bajet).
  • running: Paparan ikon berputar, tajuk langkah (cth step 3 · video_edit), pemasa saat live, dan bar kemajuan animasi nipis di bawah kad.
  • waiting_approval: Amaran menunggu kebenaran dengan butang pautan terus ke halaman Approvals.
  • quiet (peringatan ambar): Muncul selepas 2 minit tiada berita daripada ejen ("No news for 2m…"). Langkah berat seperti muat turun besar atau render mungkin mengambil masa; tekan Stop jika rasa tersangkut.
  • failed (ralat merah): Menunjukkan teks ralat lengkap tanpa terpotong (wrapped mono) berserta butang Try again.
  • cancelled (kelabu): Menunjukkan sebab job dihentikan berserta butang cuba semula.

51Model AI: Auto, 9Router, Test & Scan

Pilih dan tukar otak AI untuk setiap ejen: mod Auto pintar dengan sandaran automatik, integrasi 9Router setempat, serta alatan Test dan Scan untuk memastikan model benar-benar boleh memanggil tools.

🎯 Mod Auto & Ranking
Pilihan pintar yang mencuba senarai model terbaik mengikut ranking. Jika model pertama terkena limit/ralat, ia beralih ke model seterusnya tanpa mengulang kerja.
🌐 9Router Gateway
Gateway model setempat pada http://127.0.0.1:20128/v1. Penting: 9Router mendengar pada 127.0.0.1 sahaja. Sambungkan pelbagai model percuma Kilo Code.
🔬 Test & Scan Models
Uji satu model dengan alatan get_time atau scan sehingga 120 model serentak. Hanya model yang lulus fungsi alatan disimpan.

Mod "Auto" (Pilihan Lalai Ejen)

  • Fungsi modelCandidates() menyusun sehingga 5 model provider terbaik mengikut susunan kualiti (Claude Opus/Sonnet, GPT-5, Gemini Pro … model kecil di akhir).
  • Sandaran Automatik (Fallback): Jika model pilihan pertama gagal sebelum mengeluarkan teks atau hasil alatan (cth ralat kuota 429, 402, atau tersangkut), sistem beralih ke model seterusnya dalam senarai.
  • Kerja tidak berulang: Kerja yang sudah memanggil alatan tidak akan dimulakan dari awal, menjimatkan masa dan bajet token.

Integrasi 9Router di PC Sendiri

  • Preset sedia ada di Settings → AI providers dengan alamat http://localhost:20128/v1 tanpa perlukan API key di peringkat MyOfis.
  • Alamat IP 127.0.0.1: 9Router mendengar pada 127.0.0.1 sahaja. Jika MyOfis dijalankan dalam kontena atau server lain, masukkan alamat IP LAN mesin tersebut pada Base URL.
  • Model Kilo Code percuma: Model seperti kc/kilo-auto/free, kc/minimax/minimax-m3.1-flash:free, dan kc/nvidia/nemotron-3-ultra-550b-a55b:free berfungsi pantas (2–4 saat) dan menyokong alatan dengan baik.
  • Sistem MyOfis membersihkan jawapan non-streaming JSON + data: [DONE] secara automatik menggunakan fungsi cleanJsonText.
