MyOfis: pejabat AI awak 🏢

Manual penuh untuk semua benda dalam MyOfis (Agent Office): setiap menu, agent, butang, setting dan aliran kerja. Baca dari atas sekali; lepas tu guna kotak Cari bila perlu. Semua contoh guna setup awak sendiri: myofis.bijokdev.com, bot @MyOfis_monmon_bot, projek SmashPoint.

01Apa itu MyOfis

Satu "pejabat" berisi pekerja AI (agent) yang buat kerja sebenar untuk awak. Awak boss: awak bagi arahan, mereka buat, awak approve.

🧑‍💼 Agent
Pekerja AI. Setiap satu ada peranan, otak (model AI), tools dan watak pixel sendiri.
📋 Job
Satu tugasan untuk satu agent. Datang dari awak, chat, jadual, Telegram atau agent lain.
✅ Approval
Benda berisiko (tulis fail, push code, ubah website) tunggu awak tekan Approve dulu.

Bahagian sistem

BahagianApa diaDi mana
HubOtak pusat: database, event, jadual, approval, Telegram, backup. Port 8788.PC ni (bun run dev)
RunnerYang betul-betul jalankan agent dan tools. Boleh lebih dari satu PC.PC ni (bun run dev:runner) + PC lain (pilihan)
WebSkrin yang awak guna: pejabat, chat, drafts, setting.https://myofis.bijokdev.com
Telegram bot"Telefon pejabat": chat, approve, laporan.@MyOfis_monmon_bot

💡 Semua yang berlaku disimpan sebagai event. Sebab tu pejabat, board dan replay sentiasa sama: semuanya baca dari event yang sama.

02Cara masuk

  1. Buka https://myofis.bijokdev.com (PC atau phone).
  2. Cloudflare minta email: masukkan hazman5001@gmail.com → dapat kod 6 digit dalam email → masukkan.
  3. Siap. Login tahan lebih kurang seminggu. Tak perlu token lagi.
⚠️ localhost:5180 dan localhost:8788 tak boleh login (mod Cloudflare). Guna domain sahaja, kat PC ni pun.

08Chat

  1. Chat → pilih agent. Pilih projek kalau berkaitan (cth SmashPoint).
  2. Taip mesej. Enter hantar, Shift+Enter baris baru.
  3. 📷 Tambah gambar (sampai 4): agent nampak gambar. Klik × untuk buang sebelum hantar.
  4. 🎤 Mic: cakap, browser tukar jadi teks (Chrome/Edge, benarkan mikrofon).
  5. 🔊 Listen bawah jawapan: browser baca kuat. details: buka run penuh.
  • Thread: setiap perbualan disimpan; New mula baru. Agent ingat 10 pertukaran terakhir dalam thread.
  • Skrol: kalau awak tengah baca mesej atas, jawapan baru tak tarik awak ke bawah; keluar butang New reply ↓.
  • Setiap mesej chat satu job (kira budget, nampak di pejabat) tapi disorok dari Board.

09Publisher: post terus ke website

📷 Gambar + point→Publisher tulis→Drafts / kad Telegram→✅ Approve→Website SmashPoint+Media sosial
  1. Chat (atau Telegram) → Publisher → projek SmashPoint → 📷 gambar → point. Contoh: "Tournament doubles Sabtu 24 Okt 9 pagi, hadiah RM500, yuran RM20 seorang, daftar kat kaunter".
  2. Publisher sebut apa dalam gambar; kalau maklumat kurang dia tanya satu soalan.
  3. Dia buat post website (tajuk, ringkasan, isi, jenis, tags, tarikh/masa/tempat, cover) + caption dengan gambar sama.
  4. Drafts / kad Telegram → semak. Sebelum approve, semua medan boleh diubah: tajuk, ringkasan, jenis, tags, tarikh, masa, tempat, Change cover / Remove cover, isi.
  5. Approve → terus publish → View it on the website →.

10Drafts (inbox)

StatusMaksud

approvedDiluluskan tanpa ubah.
editedDiluluskan dengan perubahan awak (Show original tunjuk teks asal agent). Perubahan awak = pelajaran gaya.
